## Provider paths and this documentation review

The `selected-investigator` edge follows `server/hosted-runtime.mjs`, `server/runtime-service.mjs` and `server/investigation-proposal.mjs`: an explicitly configured investigator can call OpenAI or Anthropic to prepare the main proposal. Local rules remain the default. The separate advisory path reads a saved case and cannot replace its decision. Deterministic policy checks and human review follow any accepted main proposal.

The `consented-transcription` edge represents the API calling ElevenLabs speech-to-text after a signed-in person explicitly submits a bounded recording. It bypasses the saved-case action ledger; it cannot save evidence or execute a financial operation. Both new edges describe prepared call sites, not observed provider traffic. The logical provider grouping is not a shared service or a shared credential.
