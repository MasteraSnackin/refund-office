# GitHub source handover

This is the clean Refund Office source snapshot prepared on 15 October 2026 for the private `MasteraSnackin/refund-office` repository. It includes the current application, tests, setup templates, documentation, required diagrams, committed synthetic data and selected demo media.

Local databases and saved runs, provider credentials and filled environment files, dependencies, build output, working captures, delivery archives, deployment state and historical verification payloads are excluded. [ARTIFACTS.md](ARTIFACTS.md) identifies excluded local destinations referenced by copied Markdown. The originals remain in the local project; this snapshot changes only those copied link destinations and its ignore policy.

The [GitHub source verification](docs/verification-github-source-2026-10-15.md) records a successful build and 834 passing application tests against this copy. These checks used the existing local dependency installation after an offline install found a missing cached package; a fresh dependency installation was not verified. The other verification documents retain their earlier feature and account scopes. This upload does not establish a hosted deployment, successful provider connection, payment movement or production readiness.

The application remains offline by default, using synthetic cases and local analysis. External providers require their existing explicit opt-ins and private server-side configuration. Every new refund still requires the specific human approval enforced by the service. Follow the [main README](README.md) for installation and operating guidance.
